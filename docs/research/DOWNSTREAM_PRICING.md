# Downstream-aware resource-price hypothesis

Revisited [Cost-Distance Steiner Trees for Timing-Constrained Global Routing](https://arxiv.org/html/2503.04419),SectionsII/III,especially component merging,component reuse,and Steiner placement. The paper tracks aggregate sink weights when joining components and separates connection cost from weighted delay. This suggests investigating topology-aware prices here. Our prototype below is old-tree reweighting;it is not their component-merging construction and inherits no approximation guarantee. Challenge bifurcation penalties remain zero and every sink has unit physical importance.

For a coherent current tree,compute k(v),the count of sinks whose unique root path includes v. Negotiation mode1 divides each incoming vertex's congestion price by max(1,k(v));vertices outside that tree use divisor1. Mode2 uses current downstream counts where positive and preserves the old ceil(sqrt(fanout)) divisor elsewhere. Mode0 is the original uniform divisor. Price reweighting is frozen for each search and refreshed whenever a net is routed again. Physical movement cost and final delay stay unscaled;priced paths remain coherent predecessor trees. Nonnegative prices preserve the existing physical A* heuristic's consistency. Price units retain existing16-unit precision.

Counts use tree-local adjacency/order arrays. A reusable dense count lookup is allocated only when enabled;only previously touched vertices are reset between searches. Additional stress lookup memory is about6.8MB for1.69Mvertices,plus temporary arrays proportional to tree size. Flow setup wall time is recorded separately;matched expansion caps do not equal CPU cost or include flow operations as expansions. Old trees with dead leaves can have zero-count vertices. Fresh restart has no previous tree and uses fallback prices.

The identity D=sum(edge_delay*downstream_sink_count) motivates the hypothesis but does not prove that these search prices minimize sum delay plus once-per-net resource price. Existing trunks may receive favorable prices that preserve a poor topology. Unit counts and final physical acceptance do not establish global or per-net cost-distance optimality.
